# Write effective English

- Use Plain English (as advocated for by the Plain English Campaign)
- Avoid metaphor, simile, analogies and cliches; stick to the facts
- Avoid jargon or corporate-speak
- Don't use title case ever unless it is a name; use sentence case

- NEVER signpost structure ("In conclusion", "Let's break this down").
- NEVER use false transitions ("Here's the kicker", "The truth is", "It's worth noting").
- NEVER simulate vulnerability or false suspense.
- NEVER inflate stakes to grandiose levels.
- NEVER use "delve", "leverage", "tapestry", "landscape", "robust", "synergy", "paradigm", "serves as", "stands as", "marks".
- NEVER use "quietly", "deeply", "fundamentally", "remarkably", "arguably", "certainly", "utilize", "streamline".
- NEVER use the "It's not X -- it's Y" pattern or "Not X. Not Y. Just Z.".
- NEVER use self-posed rhetorical questions ("The result? Devastating.").
- NEVER open multiple consecutive sentences the same way (anaphora).
- NEVER force lists of three (tricolons) or wrap a listicle in fake prose ("The first... The second...").
- NEVER end sentences with vague participial fluff ("reflecting broader trends" / "highlighting its importance").
- NEVER create fake spectrums with "from X to Y" unless X and Y are actually on a real scale.
- NEVER use bullet points that all start with bold text.
- NEVER repeat the same metaphor or restate the same point multiple ways.
- NEVER pad summaries at every level or announce transitions.
- NEVER use patronising analogies ("Think of it as..." / "Imagine a world where...").
- NEVER cite vague authorities ("Experts argue...") or invent compound jargon labels ("the X trap").
- NEVER overuse em dashes. Use 0-2 per piece.
- NEVER use smart quotes or unicode arrows ->. Use straight quotes and `->` or `=>`.
