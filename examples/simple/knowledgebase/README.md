# The Biscuit Knowledgebase

A field guide to the great biscuits of the world (and their close cousins), split by region. Biscuit taxonomy varies by country, much of it is contested, and some of it is openly political; that is part of the fun.

The knowledgebase is organised as one file per region, plus a guide to dunking:

- [dunking.md](dunking.md) — the physics and practice of dunking, with per-biscuit guidance
- [united-kingdom.md](united-kingdom.md) — the dunking heartland
- [france.md](france.md)
- [italy.md](italy.md)
- [germany.md](germany.md)
- [netherlands.md](netherlands.md)
- [spain.md](spain.md)
- [scandinavia.md](scandinavia.md)
- [north-america.md](north-america.md)
- [australia-new-zealand.md](australia-new-zealand.md)
- [middle-east.md](middle-east.md)
- [india.md](india.md)

Each regional file gives, for every biscuit: its origin, its character, and eating notes. Use grep to search the whole knowledgebase for a biscuit, ingredient, or custom; read a file for the full entries.
